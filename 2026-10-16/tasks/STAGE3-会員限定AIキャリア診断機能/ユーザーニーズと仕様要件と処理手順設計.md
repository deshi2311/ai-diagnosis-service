# STAGE3 会員限定AIキャリア診断機能

**日付**: 2026-10-16  
**対象**: AIキャリア診断サービス  
**前提**: Stage2 Google認証（JWT + MongoDB Adapter）済み

---

## 1. ユーザーニーズ

| ユーザー | ニーズ | 応え方 |
|----------|--------|--------|
| 会員 | 5問で自分のキャリアの方向性を知りたい | `/diagnosis` フォーム → AI分析 |
| 会員 | 結果をあとから見返したい | 履歴一覧・詳細 |
| 会員 | 結果を手直ししたい／不要なら消したい | 編集・削除 |
| 未ログイン | 診断は会員だけにしたい | `/diagnosis` 以下を認証必須 |
| 運営 | 失敗したAI応答を成功扱いにしたくない | stop_reason 監視・失敗時は未保存 |

---

## 2. 仕様要件

### 2.1 ページ

| パス | 内容 |
|------|------|
| `/diagnosis` | 5問フォーム。送信で `POST /api/diagnosis` |
| `/diagnosis/result?id=` | 直後の結果表示（詳細へ誘導） |
| `/diagnosis/history` | 自分の診断一覧 |
| `/diagnosis/[id]` | 詳細（結果・ロードマップ・編集/削除） |
| `/diagnosis/[id]/edit` | 結果・ロードマップの編集 |

### 2.2 API

| Method | Path | 内容 |
|--------|------|------|
| POST | `/api/diagnosis` | AI実行＋成功時のみ保存 |
| GET | `/api/diagnosis` | 履歴一覧（自分のみ） |
| GET | `/api/diagnosis/[id]` | 詳細（自分のみ） |
| PUT | `/api/diagnosis/[id]` | 更新（自分のみ） |
| DELETE | `/api/diagnosis/[id]` | 削除（自分のみ） |

### 2.3 Diagnosis（Mongoose）

- `userId` ObjectId
- `answers` Object（5問）
- `result` Object（AI分析）
- `careerRoadmap` Object（短期・中期・長期）
- `createdAt` / `updatedAt`

### 2.4 Claude（Haiku 5.5）

- モデルID: `claude-haiku-5-5`
- `max_tokens: 8192`（出発点）
- `output_config: { effort: 'low' }`
- thinking / budget_tokens / temperature / top_p / top_k は送らない
- messages 末尾はユーザー発話
- 本文は `type === 'text'` のみ結合
- `stop_reason` が `refusal` / `max_tokens` / `model_context_window_exceeded` のときは失敗扱い・未保存
- usage から費用試算（2026-10-11 単価）

### 2.5 認証

middleware / `authorized` で `/diagnosis` 以下を保護。

---

## 3. 処理手順

### 3.1 診断実行

1. 会員チェック
2. 5問バリデーション
3. Claude 呼び出し
4. stop_reason / JSON パース確認
5. 成功時のみ Diagnosis 保存 → `{ id }` 返却
6. クライアントは `/diagnosis/result?id=` へ遷移

### 3.2 CRUD

一覧・詳細・更新・削除はすべて `userId === session.user.id` でフィルタ。

### 3.3 5問（初期）

1. 今の状況（就活／転職／キャリア再設計）
2. 大切にしたい価値観
3. 得意・好きなこと
4. 避けたいこと・弱み
5. 1〜3年後に目指したい姿
