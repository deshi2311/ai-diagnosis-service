# ユーザージャーニーマップ

**対象フロー**: LP訪問 → 内容理解 → CTA押下  
**スコープ**: Stage1（トップページのみ。診断画面以降は対象外）

---

## ジャーニー概要

```
流入 → ヒーロー認知 → 課題共感 → 特徴理解 → 結果イメージ → 流れ確認 → 不安解消 → CTA押下
```

| フェーズ | ユーザーの状態 | 主な接触セクション |
|----------|----------------|--------------------|
| 1. 流入・第一印象 | 興味・警戒が混在 | ヒーロー |
| 2. 課題共感 | 「自分向けかも」 | 課題提起 |
| 3. 価値理解 | 「使えそう」 | サービス特徴 / 診断でわかること |
| 4. 行動イメージ | 「できそう」 | 診断の流れ |
| 5. 不安解消 | 「やってみよう」 | FAQ |
| 6. 行動決定 | CTA押下 | ヒーローCTA / 下部CTA |

---

## フェーズ別詳細

### Phase 1. 流入・第一印象（ヒーローセクション）

| 項目 | 内容 |
|------|------|
| タッチポイント | 検索、SNS、友人共有、広告 など → LPトップ |
| 行動 | キャッチコピー・サブコピーを読む。スクロールするか即離脱するか判断 |
| 思考 | 「5問で本当にわかる？」「自分向け？」「怪しくない？」 |
| 感情 | 興味 ＋ 半信半疑 |
| 痛み・障壁 | キャッチが抽象的／所要時間が不明／信頼要素がない |
| 機会（Opportunity） | 「5問」「キャリアロードマップ」でベネフィットと手軽さを同時に伝える |
| KPI候補 | 直帰率、ヒーローCTAクリック率、ファーストビュー滞在時間 |

**体験目標**: 3秒以内に「誰向け・何が得られる・どれくらい簡単か」が伝わること。

---

### Phase 2. 課題共感（課題提起セクション）

| 項目 | 内容 |
|------|------|
| タッチポイント | 「こんなお悩みありませんか？」＋悩み3つ |
| 行動 | 自分の悩みに近い項目を探す。スクロール継続を決める |
| 思考 | 「これ、自分のことだ」「就活／転職／キャリア迷子のどれか」 |
| 感情 | 共感・安心（一人じゃない） |
| 痛み・障壁 | 悩みが自分とズレていると離脱。一般論すぎると刺さらない |
| 機会 | P1〜P3の悩みをカバーする3項目にする（業界未定／転職迷い／方向性不安 等） |
| KPI候補 | 当該セクション到達率、スクロール深度 |

**体験目標**: ターゲット3タイプのいずれかが「自分向け」と感じること。

---

### Phase 3. 価値理解（サービス特徴 / 診断でわかること）

| 項目 | 内容 |
|------|------|
| タッチポイント | 特徴3つ、診断結果に含まれる項目3つ |
| 行動 | 「他サービスと何が違うか」「結果に何が出るか」を読む |
| 思考 | 「AIでロードマップ？」「結果は具体的？」「自分に役立つの？」 |
| 感情 | 期待上昇、または「まだ曖昧」で不安 |
| 痛み・障壁 | 特徴が抽象的／結果イメージが弱いと信頼が積み上がらない |
| 機会 | 特徴＝手軽さ・AI分析・ロードマップ。結果項目＝職種適性・強み・次の一歩 等を具体化 |
| KPI候補 | 中間セクション到達率、中間CTAがあればクリック率 |

**体験目標**: 「診断後に何が手に入るか」が具体的に想像できること。

---

### Phase 4. 行動イメージ（診断の流れ・3ステップ）

| 項目 | 内容 |
|------|------|
| タッチポイント | ステップ1〜3の説明 |
| 行動 | 所要時間・手順の簡単さを確認 |
| 思考 | 「登録必要？」「すぐ終わる？」「途中で止められる？」 |
| 感情 | 「やれそう」→ 行動意欲上昇 |
| 痛み・障壁 | ステップが多そう／会員登録必須に見えると離脱 |
| 機会 | 「質問に答える → AI分析 → 結果表示」を簡潔に。所要時間を明記 |
| KPI候補 | 流れセクション到達率 |

**体験目標**: 「今すぐ5分以内でできそう」と感じさせること。

---

### Phase 5. 不安解消（FAQ）

| 項目 | 内容 |
|------|------|
| タッチポイント | よくある質問 3問 |
| 行動 | 気になる質問を開く／読む |
| 思考 | 「無料？」「データは大丈夫？」「精度は？」 |
| 感情 | 不安の軽減 or 残存 |
| 痛み・障壁 | FAQが的外れだと下部CTAまで進まない |
| 機会 | 想定Q: 所要時間／無料かどうか／結果の活用方法（Stage1で答えられる範囲） |
| KPI候補 | FAQ開閉率（実装する場合）、下部セクション到達率 |

**体験目標**: CTA前の典型的な不安を3つ以内で解消すること。

---

### Phase 6. 行動決定（CTAセクション → CTA押下）

| 項目 | 内容 |
|------|------|
| タッチポイント | ページ下部の見出し＋CTAボタン（およびヒーローCTA） |
| 行動 | CTAボタンをタップ／クリック |
| 思考 | 「やってみよう」「とりあえず試す」 |
| 感情 | 決意・軽やかな期待 |
| 痛み・障壁 | CTA文言が弱い／次画面が不明／ボタンが目立たない |
| 機会 | 「無料で診断する」「5問から始める」など行動が明確な文言。押下後は診断画面へ（Stage2以降） |
| KPI候補 | **CTAクリック率（一次KPI）**、ヒーローCTA vs 下部CTAの比率 |

**体験目標**: 迷わず診断開始できること。Stage1では「導線としてのCTA押下」までを成功とする。

## ペルソナ別ジャーニーの違い

| フェーズ | P1 アヤ（就活） | P2 ケンタ（転職） | P3 ミカ（再設計） |
|----------|-----------------|-------------------|-------------------|
| 流入 | 就活系キーワード・SNS | 転職・適性診断検索 | キャリア診断・ロードマップ検索 |
| 共感で見る点 | 業界・職種が決まらない | 続ける／変えるの迷い | 中長期の方向性 |
| 信頼の決め手 | 手軽さ・時間 | 結果の実用性 | FAQ・結果の具体性 |
| CTAのトリガー | 「すぐ終わる」 | 「選択肢が見える」 | 「まず試せる」 |
| 離脱しやすい点 | 文字が多い／PC前提の見た目 | 学生向けに見える表現 | 無料診断への不信 |

## ジャーニー上の成功定義（Stage1）

| レベル | 定義 |
|--------|------|
| 最低限成功 | LP閲覧後、いずれかのCTAを押下 |
| 理想成功 | 課題共感〜結果イメージまで読んだうえでCTA押下（深い理解からの転換） |
| 失敗 | ヒーローで直帰、または中盤で離脱しCTA未到達 |
