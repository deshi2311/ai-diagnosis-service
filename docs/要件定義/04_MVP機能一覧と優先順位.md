# MVP機能一覧と優先順位

**プロダクト**: 5問でわかる、あなたのキャリア  
**技術スタック**: Next.js 15 / App Router / MUI  
**Stage1スコープ**: トップページ（LP）のみ — サービス紹介・特徴・診断へのCTA

---

## 1. MVPの定義

| 項目 | 内容 |
|------|------|
| Stage1 MVP | 8セクション構成のLPを公開し、診断開始CTAまでユーザーを導けること |
| 成功指標（一次） | CTAクリック率 |
| 成功指標（二次） | 直帰率低下、下部CTA到達率、モバイルでの可読性 |
| 対象外（Stage1） | 診断質問UI、AI分析、結果表示、会員登録、決済 |

Stage1のMVPは「診断プロダクトそのもの」ではなく、**診断へ送客するLPの完成**とする。

---

## 2. 優先度の定義

| 優先度 | 意味 | リリース判断 |
|--------|------|--------------|
| P0 | Stage1リリースに必須 | 未実装ならリリース不可 |
| P1 | あると転換・信頼性に効く | 可能な限り同リリース |
| P2 | 改善・拡張 | Stage1後でも可 |
| P3 | 将来検討 | 当面やらない |

## 4. コンテンツ要件（Stage1で決める中身）

実装前にコピー・項目内容を確定する。優先度はすべて **P0（コンテンツ未定ならデザインのみでリリースしない）**。

| セクション | 確定が必要な項目 | 初期案の方向性 |
|------------|------------------|----------------|
| ヒーロー | キャッチ、サブ、CTA文言 | キャッチ固定。サブは「AIが適正なキャリアロードマップを作成」系 |
| 課題提起 | 悩み3つ | ①業界・職種が決まらない ②転職すべきか迷う ③将来の方向性が見えない |
| 特徴 | 特徴3つ | ①5問で完結 ②AIによる分析 ③キャリアロードマップ提示 |
| わかること | 結果項目3つ | ①適性キャリアの方向性 ②強み・傾向 ③次に取るべきステップ |
| 流れ | ステップ3つ | ①5問に回答 ②AIが分析 ③ロードマップを確認 |
| FAQ | 質問・回答3組 | 例: 所要時間／費用／結果の使い方 |
| CTA | 見出し・ボタン文言 | 例:「今すぐキャリア診断を始める」 |
| フッター | 著作権表記 | サービス名・年 |

## 6. リリース優先順位（推奨ロードマップ）

### Wave 1 — Stage1 MVP（必須）

1. Next.js 15 + MUI プロジェクト骨格  
2. LP 8セクション静的実装（LP-01〜08）  
3. レスポンシブ（LP-09）  
4. CTA 2箇所＋診断ルートへのリンク（LP-10, LP-15）  
5. テーマ・基本アクセシビリティ（LP-21, LP-23）

### Wave 2 — Stage1 強化（同リリース推奨）

1. FAQアコーディオン（LP-12）  
2. メタ／OGP（LP-18）  
3. CTA計測（LP-16）  
4. セクションコンポーネント整理（LP-22）  
5. 画像・パフォーマンス（LP-24）

### Wave 3 — Stage1 改善

1. 中間CTA、到達計測、軽いモーション（LP-11, 14, 17, 19）  
2. コピーA/B、悩み文言の最適化  

### Wave 4 — Stage2（診断MVP）

1. DX-01〜05（質問〜結果）  
2. CTAリンク先を本番診断に接続

## 7. 受け入れ条件（Stage1 Doneの定義）

- [ ] 8セクションがすべて表示される  
- [ ] ヒーロー・下部のCTAが押せる（遷移先はプレースホルダでも可）  
- [ ] スマホ幅で主要テキスト・CTAが欠けない  
- [ ] 悩み3・特徴3・わかること3・流れ3・FAQ3がコンテンツとして埋まっている  
- [ ] フッターに著作権表示がある  
- [ ] Next.js 15 App Router + MUI で実装されている  

---

## 8. スコープ外（明示）

| 対象外 | 理由 |
|--------|------|
| 診断ロジック・AIプロンプト本番接続 | Stage2 |
| ログイン・マイページ | 初期ハードルを上げるため後回し |
| CMSによるLP編集 | 静的で十分な段階 |
| 多言語 | ターゲットが国内20〜30代想定 |
| デザインシステムの完全整備 | LP単ページに必要な範囲に限定 |
