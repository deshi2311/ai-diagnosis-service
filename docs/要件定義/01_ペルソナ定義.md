# ペルソナ定義

**サービス名**: 5問でわかる、あなたのキャリア  
**対象**: 就活中の学生、転職を考えている社会人、キャリアに悩む20〜30代  
**作成対象**: Stage1 LP（トップページ）

---

## ペルソナ一覧（3タイプ）

| # | ペルソナ名 | 属性 | 主な悩み |
|---|------------|------|----------|
| P1 | 就活迷子の大学生・アヤ | 大学3〜4年生 | 業界・職種が決まらない |
| P2 | 転職検討中の社会人・ケンタ | 社会人3〜7年目 | 今の会社を続けるべきか迷う |
| P3 | キャリア再設計したい社会人・ミカ | 社会人8〜12年目 | キャリアの方向性が見えない |

## P1. 就活迷子の大学生・アヤ

### 基本情報

| 項目 | 内容 |
|------|------|
| 名前 | 田中 彩（たなか あや） |
| 年齢 | 22歳 |
| 属性 | 私立大学3年生（文学部） |
| 居住地 | 東京都（一人暮らし） |
| 就活状況 | インターン・説明会に参加し始めた段階 |
| デバイス | スマホ中心（通勤・隙間時間） |

### 背景・状況

- 周囲は就活を始めているが、自分は「何がやりたいか」が言語化できていない
- 自己分析シートは書いたが、結論がぼんやりしたまま
- 企業の説明会に行くほど「全部よさそう」に見え、逆に迷う
- 友人は早期内定を取り始めており、焦りがある

### ゴール

- 自分に合いそうな業界・職種の候補を短時間で知りたい
- 「何から考えればいいか」の道筋がほしい
- 就活エージェントや友人に話す前の、自分なりの軸がほしい

### 課題・ペイン

1. **自己分析が深まらない** — 長時間かけても答えが出ない
2. **情報過多で選べない** — 企業・業界情報が多すぎて判断できない
3. **時間がない** — 授業・バイト・就活準備でまとまった時間が取れない
4. **自信がない** — 「この選択で合っているのか」を誰かに保証してほしい

### LPへの期待行動

- スマホでLPを開き、キャッチコピーで「5問でわかる」に惹かれる
- 悩み共感セクションで「自分のことだ」と感じる
- CTAから診断へ進む（所要時間の短さを重視）

### 刺さるメッセージ例

- 「5問でわかる、あなたのキャリア」
- 「業界・職種が決まらないあなたへ」
- 「自己分析に何時間もかけなくていい」

## P2. 転職検討中の社会人・ケンタ

### 基本情報

| 項目 | 内容 |
|------|------|
| 名前 | 佐藤 健太（さとう けんた） |
| 年齢 | 28歳 |
| 属性 | IT企業の営業職（社会人5年目） |
| 居住地 | 神奈川県（実家暮らし） |
| 転職状況 | 情報収集中。求人サイトは見ているが応募はしていない |
| デバイス | PC（夜）＋スマホ（昼休み） |

### 背景・状況

- 今の仕事に大きな不満はないが、成長実感が薄れてきた
- 「このまま営業を続けるべきか」「専門職に転向すべきか」で迷っている
- 転職サイトは見るが、求人の多さに圧倒され応募に至らない
- 友人の転職成功談を聞き、「自分も動かないと」と感じている

### ゴール

- 自分の強み・適性が客観的に知りたい
- 転職すべきか、今の会社で伸ばすべきかの判断材料がほしい
- 次のキャリアの選択肢を整理したい

### 課題・ペイン

1. **現状維持バイアス** — 辞めるほどの不満がなく、行動が先延ばしになる
2. **自己評価の偏り** — 自分の市場価値がわからない
3. **選択肢の整理不足** — 職種・業界の候補が散らばっている
4. **時間効率** — 長い診断やカウンセリングはハードルが高い

### LPへの期待行動

- 昼休みや夜にスマホ／PCで検索し、LPに流入
- 「転職を考えている人向け」の特徴・診断結果イメージで信頼を得る
- 流れ（3ステップ）で手軽さを確認し、CTAを押す

### 刺さるメッセージ例

- 「今の仕事、続ける？変える？」
- 「5問で、次のキャリアの選択肢が見える」
- 「診断結果にロードマップ付き」

## P3. キャリア再設計したい社会人・ミカ

### 基本情報

| 項目 | 内容 |
|------|------|
| 名前 | 鈴木 美香（すずき みか） |
| 年齢 | 33歳 |
| 属性 | メーカー勤務の企画職（社会人11年目） |
| 居住地 | 大阪府（既婚・子どもなし） |
| キャリア状況 | 昇進・異動の話はあるが、長期の方向性に不安 |
| デバイス | PC中心（在宅日）、スマホも併用 |

### 背景・状況

- 「このまま同じ会社で管理職を目指すのか」「別の専門性を磨くのか」が決まらない
- 過去の転職は一度のみ。次を失敗したくない慎重さがある
- キャリア相談は有料・対面が多く、まずは手軽に試したい
- ライフイベント（将来の育児など）も視野に入れた働き方を考えたい

### ゴール

- これまでの経験を踏まえた、中長期のキャリアの方向性がほしい
- 診断結果をきっかけに、自分で・または専門家と深掘りしたい
- 「なんとなく不安」を具体的な論点に落としたい

### 課題・ペイン

1. **長期視点の欠如** — 目の前の仕事に追われ、キャリア設計ができていない
2. **情報の信頼性** — 無料診断の精度・実用性への懐疑
3. **行動のハードル** — いきなりカウンセリングは重い
4. **結果の活用イメージ不足** — 診断後に何ができるかがわからないと離脱する

### LPへの期待行動

- 「診断でわかること」「FAQ」で信頼・実用性を確認してからCTA
- 特徴・流れを読み込み、短時間で完結することを重視
- 結果イメージ（ロードマップ等）が具体的だと行動しやすい

### 刺さるメッセージ例

- 「キャリアに悩む20〜30代へ」
- 「5問で、あなたのキャリアロードマップ」
- 「まずは気軽に。結果はすぐわかる」

## ペルソナ横断の示唆（LP設計への反映）

| 観点 | 共通ニーズ | LPへの反映 |
|------|------------|------------|
| 所要時間 | 短く完結したい | ヒーロー・流れで「5問」「○分」を明示 |
| 共感 | 自分ごと化したい | 課題提起で3タイプの悩みをカバー |
| 信頼 | 結果が役に立つか知りたい | 「診断でわかること」で成果物を具体化 |
| 行動 | ハードルを下げたい | CTAを複数配置、流れを3ステップで簡略化 |
| デバイス | スマホ利用が多い | レスポンシブ必須（Stage1要件に含める） |
| トーン | 押し売り感を避けたい | 診断への導線に留め、過度な煽りを避ける |
