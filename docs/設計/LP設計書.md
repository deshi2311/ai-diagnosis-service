## 2. ヘッダー設計（必須）

| 項目 | 仕様 |
|------|------|
| 配置 | ページ最上部。ヒーローの前。`AppBar` + `Toolbar`、`position="static"` |
| 本文との関係 | fixed/sticky にしない。本文を覆わない |
| サービス名 | 「AIキャリア診断サービス」（別名称を作らない）。テキストロゴ。クリックで `#`（ページ先頭）へ |
| ナビ | 「特徴」→ `#features` / 「診断の流れ」→ `#steps` / 「FAQ」→ `#faq` |
| CTA | 「無料で診断を始める」。ヒーロー・下部CTAと同一挙動（Stage1: Coming Soon） |
| レスポンシブ | PC/タブレット/スマホでサービス名・ナビ・CTAを表示。狭い画面は折り返しで横はみ出し・重なり・欠落を防ぐ |

### ヘッダー ワイヤー（PC）

```
| AIキャリア診断サービス     特徴   診断の流れ   FAQ   [無料で診断を始める] |
```

### ヘッダー ワイヤー（狭い画面）

```
| AIキャリア診断サービス              [無料で診断を始める] |
| 特徴          診断の流れ          FAQ                  |
```

折り返しにより全要素を表示する（ハンバーガーで隠さない）。

## 3. セクション詳細

### 3.1 ヒーロー

| 項目 | 内容 |
|------|------|
| キャッチ | 5問でわかる、あなたのキャリア |

| # | 項目 |
|---|------|

### 3.5 ステップ（`id="steps"`）

| Step | 内容 |
|------|------|

### 3.6 FAQ（`id="faq"`）

| Q | A |

### 3.7 下部CTA

|------|------|

## 4. CTA挙動（Stage1）

| 配置 | ラベル | 挙動 |
|------|--------|------|
| ヘッダー | 無料で診断を始める | クリックで「Coming Soon」表示（SnackBar）。認証・診断ページは作らない |

## 5. デザイン方針

| 項目 | 方針 |
|------|------|
| UIライブラリ | MUI |
| カラー | プライマリ青系。CTAは青グラデーションで目立たせる |
| トーン | モダン・信頼感。過度な煽りや装飾を避ける |
| タイポ | 見出しは大きめ・太め。本文は読みやすい行間 |
| カード | 課題・特徴はカード（角丸・軽い影） |
| レスポンシブ | `xs` / `sm` / `md` 以上でグリッド列数を切替 |

### カラー変数（テーマ）

| トークン | 用途 |
|----------|------|
| `primary.main` | `#1565C0` |
| CTAグラデーション | `#1565C0 → #42A5F5` |
| 背景 | `#F7FAFC` / ヒーローは淡い青グラデ |
| テキスト | `#1A2027` / サブ `#5A6A7A` |

## 6. コンポーネント構成

```
app/
  layout.tsx          … ThemeRegistry（MUI）
  page.tsx            … ヘッダー + 8セクション組み立て
  theme.ts            … MUIテーマ
  components/
    Header.tsx
    HeroSection.tsx
    ProblemsSection.tsx
    FeaturesSection.tsx
    ResultsSection.tsx
    StepsSection.tsx
    FaqSection.tsx
    CtaSection.tsx
    Footer.tsx
    CtaButton.tsx     … 共通CTA（グラデーション）
```

### アンカーID

| セクション | id |
|------------|-----|
| 特徴 | `features` |
| 診断の流れ | `steps` |
| FAQ | `faq` |

ページ先頭への復帰はサービス名リンクで `window.scrollTo` または `#top`（`id="top"` をルートに付与）。

## 7. レスポンシブ仕様

| 要素 | PC (md+) | タブレット (sm) | スマホ (xs) |
|------|----------|-----------------|-------------|
| ヘッダー | 1行（名＋ナビ＋CTA） | 折り返し可 | 名＋CTA / 下段ナビ |
| 課題・特徴カード | 3列 | 2〜3列 | 1列 |
| わかること | 3列 | 3列 or 縦積 | 縦積 |
| ステップ | 横3 | 横3 or 縦 | 縦 |
| CTAボタン | 幅自動 | 幅自動 | ほぼ全幅可 |
