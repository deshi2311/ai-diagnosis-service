# オーナー管理画面 動作確認チェックリスト

**対象**: AIキャリア診断サービス Stage4（管理者ダッシュボード）  
**確認URL**: `http://localhost:3000`（本番がある場合はそのURL）  
**前提環境**:
- `.env.local` に `ADMIN_EMAILS`（管理者の Google メール）設定済み
- `MONGODB_URI` / Google OAuth / `AUTH_SECRET` 設定済み
- `npm run dev` 起動済み
- 確認用アカウントが2種類あること  
  - **管理者**: `ADMIN_EMAILS` に含まれるメール（または DB `users.role = admin`）  
  - **一般ユーザー**: 上記以外のメール（`role = user`）

**確認日**: 2026 / 10 / 21  
**確認者**: Auto（`scripts/admin-checklist-verify.mjs` + ローカル Playwright）  
**管理者アカウント（メールのみ）**: ADMIN_EMAILS 先頭（提出物に値は書かない）  
**一般ユーザーアカウント（メールのみ）**: DB 上の別ユーザー  

**検証方法メモ**: Google の対話ログインは自動化できないため、DB で `role=admin` を確定したうえで NextAuth JWT を発行し、Edge 相当のブラウザで `/admin` 配下を確認した。未ログイン／一般ユーザー拒否も同スクリプトで確認。

## 注意（実装仕様との差分）

- 管理**画面**の一般ユーザー拒否は、現状 **`/dashboard` へのリダイレクト**が主。HTTP 403 は主に **`/api/admin/*`** で返す。
- `ADMIN_EMAILS` は**初回ロール付与**に使われる。既に `role: user` のユーザーは、再ログイン時に JWT へ載らない場合があるため、DB の `role` を確認すること。
- CSV・一覧にパスワード、トークン、診断回答全文が出ていないことを必ず見る。
- 本チェックリスト自体に `.env` の値・Cookie・個人の診断回答を書かない。
